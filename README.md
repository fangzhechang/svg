## svg
Go library for parsing svg files.  
Includes Bezier Curve rasterization.

Currently used for [svg2kicad](http://github.com/rustyoz/svg2kicad)

## about this repo
This repo was forked from [rustyoz/svg](https://github.com/rustyoz/svg) to 
fix some issues in the original code base. Please refer to the original repo
[rustyoz/svg](https://github.com/rustyoz/svg) which has already integrated 
the related fixes.
